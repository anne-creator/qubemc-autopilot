# QubeMC Autopilot

A standalone Astro preview of Autopilot for game hosting teams. The page opens at the site root. Its incident cards show an example workflow.

Run `npm ci`, then `npm run dev`. Run `npm run check` for Astro diagnostics and `npm run build` to generate the static site in `dist/`.

The preview comes from QubeMC's Autopilot source at revision `6a56773`. This package uses the [Doto display font](https://github.com/oliverlalan/Doto) and IBM Plex Mono. Both font licenses are included in `public/assets/fonts/`. The contact button goes to QubeMC's existing contact page.
